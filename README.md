# worker-registry

Программа учёта работников ООО «Турбо» (бренд «Турбо Облако», ГК «РТК-ЦОД»).
Кейс-задача № 3 производственной практики, направление 02.03.03.

## Состав

| Файл | Назначение |
| --- | --- |
| `worker_registry/worker.py` | Модуль с классом `WORKER` и реестром `WorkerRegistry` |
| `main.py` | Консольная программа: ввод, фильтр по стажу, вывод |
| `tests/test_worker.py` | Тесты pytest (13 тестов) |

## Класс WORKER

Поля (закрытые, доступ через свойства):

- `full_name` — фамилия и инициалы;
- `position` — название должности;
- `salary` — зарплата (`Decimal`, 2 знака);
- `hire_year` — год поступления на работу.

Конструкторы: `WORKER()` по умолчанию, `WORKER(full_name, position, salary, hire_year)`,
`WORKER.from_name_and_position()`, `WORKER.from_csv_line()`, `WORKER.from_dict()`.

Деструктор: `__del__` уменьшает счётчик объектов `WORKER.instances()`.

Методы: `update()` — изменение полей, `display()` — строка для вывода,
`seniority()` — стаж в полных годах, `to_dict()`.

Реестр `WorkerRegistry` хранит объекты в `list` и выполняет выборку
`names_with_seniority_over(years)`.

## Запуск

```bash
python main.py
```

Пример сеанса:

```
Сколько работников ввести? 2

Работник № 1
  Фамилия и инициалы: Иванов И. И.
  Должность: ML-инженер
  Зарплата, руб.: 250000
  Год поступления на работу: 2019

Работник № 2
  Фамилия и инициалы: Петров П. П.
  Должность: Разработчик
  Зарплата, руб.: 180000
  Год поступления на работу: 2024

Введите стаж (полных лет). Показать работников со стажем больше: 5

Работники со стажем больше 5 лет:
  - Иванов И. И.
```

Если подходящих работников нет, программа выводит:
`Работников со стажем больше N лет нет.`
